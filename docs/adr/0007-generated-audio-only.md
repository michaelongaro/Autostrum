# Generated Web Audio playback only (no recordings or YouTube)

Other tab sites often lean on YouTube or user audio. Autostrum treats accurate, tool-generated playback as the product: Soundfont + Web Audio from the tab document only. User-uploaded recordings and YouTube embeds were rejected as niche, complex, and opposed to minimizing the work to create an accurate tab. That bounds scope, but forgoes authenticity cues external media would provide.
