# Guitar recordings

These banks are prepared from original WAV recordings, served locally, and
published under CC0 1.0. Each directory includes its license and source mapping.

- steel: Meta Steel Guitar — 375 string-specific recordings, three dynamics.
- nylon: Meta Nylon Guitar — 348 string-specific recordings; finger/light/firm pick.
- electric: Karoryfer Emilyguitar — 216 direct recordings, four dynamics, three takes.

Meta Creative Audio recorded the acoustics. D. Smolken / Karoryfer Lecolds
recorded and mapped Emilyguitar. Jazz uses the electric bank with a darker tone.
The sampler loads first-position references, then prepares string positions for
the current piece. Hashed MP3s use immutable caching; manifests revalidate.

See `decisions/guitar-samples.md` for source URLs, archive checksums, conversion,
loading, sampling limitations and browser checks.
